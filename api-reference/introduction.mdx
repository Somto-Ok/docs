## Welcome

This documentation provides a comprehensive overview of the BoldBank API endpoints and how to interact with them. Below, you'll find sections for authentication and details on the various endpoints available.

## Authentication

All API endpoints require authentication using public and secret keys. Include both keys in the request headers to authorize your API calls.

```json
"headers": {
  "x-api-key": "your_public_key",
  "x-api-secret": "your_secret_key"
}
